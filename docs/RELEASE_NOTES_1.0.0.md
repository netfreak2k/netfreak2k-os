# Netfreak2k Server-OS 1.0.0

Netfreak2k Server-OS 1.0.0 is the first stable release of the browser-managed server platform.

## Highlights

- Golden Glass server dashboard
- Home Assistant OS via KVM/libvirt
- Docker app management with resources, logs and update checks
- Storage 2.0 with inventory, SMART and controlled mounts
- Network 2.0 with device history, diagnostics and Wake-on-LAN
- Virtualization 2.0 with VM resources, controls and snapshots
- Backup & Recovery 2.0 with verification and restore tests
- safe OS update preflight with verified recovery point
- roles, sessions and TOTP 2FA
- host security hardening diagnostics
- configurable monitoring, quiet hours and maintenance mode
- remote connectivity diagnostics
- Jobs & Scheduler
- unified Logs & Events
- Recovery Center and v1.0 release-readiness checks
