# Design, Branding and Copyright Policy

## Purpose

Netfreak2k Server-OS uses an original visual system called **N2K Golden Glass**.

The goal is a premium, translucent desktop-style interface with soft depth, rounded geometry, layered glass, warm light, compact navigation and a desktop/cloud control-center feel.

## Explicit non-copying rules

The project must not copy or redistribute proprietary Apple assets.

Do not include:

- Apple logos or trademarks
- proprietary Apple fonts
- macOS wallpapers
- Apple system icons or SF Symbols
- copied screenshots as production assets
- copied interface source code
- proprietary sound effects
- Apple application icons
- exact pixel-for-pixel reproductions of macOS screens

The visual direction may use general design ideas that are not tied to a proprietary asset, for example translucency, blur, rounded windows, layered surfaces, depth, restrained animation and desktop-like navigation.

## Golden Glass identity

Golden Glass deliberately differs from Apple branding through:

- the N2K wordmark and Netfreak2k Server-OS product name
- warm gold/amber light as the primary accent
- custom N2K component proportions
- custom navigation labels and server/cloud information architecture
- generic Unicode placeholders until a separately licensed icon set is selected
- system-ui font stacks rather than Apple-proprietary fonts
- original background gradients generated in CSS

## Asset policy

Every future icon, wallpaper, font, illustration, audio asset or code dependency added to the repository must have:

1. a known source,
2. a compatible license,
3. attribution where required,
4. redistribution permission where required,
5. an entry in `THIRD_PARTY_NOTICES.md` when it is shipped or depended on.

Unknown-license assets must not be committed.

## Trademark wording

Documentation may describe the UX as "macOS-inspired" for comparison, but the product itself must not present as macOS, Apple software, or an Apple product.

"Golden Gate" is treated only as a user-supplied design reference. The product design name used in this repository is **N2K Golden Glass**.
