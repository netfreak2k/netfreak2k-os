# Computer checkpoint

Most repository preparation can be performed remotely.

A physical computer or VM console becomes necessary when the project reaches these tasks:

1. boot the generated ISO in a graphical VM
2. visually inspect N2K desktop behavior
3. test the graphical installer and partitioning
4. validate suspend/resume
5. test real Wi-Fi, Bluetooth, audio, webcam and GPU hardware
6. test Raspberry Pi boot and device-specific firmware

Until that point, work should continue through GitHub, CI, configuration, scripts and documentation.
