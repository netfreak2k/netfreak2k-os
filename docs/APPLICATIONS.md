# Required Desktop Applications

Netfreak2k OS aims to be usable as a complete lightweight everyday Linux desktop.

## Required

### Web
- Google Chrome
- support for standard web applications and PWAs
- validation for YouTube and mainstream streaming services
- DRM-dependent services documented per architecture/build

### AI
- N2K AI Dashboard
- user-customizable tiles and shortcuts
- ChatGPT access through the user's browser session
- future optional local-AI providers

### Productivity
- office suite with word processing, spreadsheet and presentation support
- PDF viewer
- text editor / notes
- archive manager

### Media
- audio/video player
- radio application
- image viewer
- screenshot utility

### System
- file manager
- N2K Terminal
- settings
- software/update manager
- system monitor
- backup/recovery assistant
- network controls
- Bluetooth controls
- audio controls
- storage/removable-media tools

## Pi 3 rule

Default applications must be chosen with memory and startup cost in mind. Heavy services should not run continuously when an on-demand alternative is sufficient.

Where a full application is too heavy for the Pi 3 profile, the project may provide a lightweight default while keeping a fuller option available for stronger hardware.
